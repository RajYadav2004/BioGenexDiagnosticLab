# Biogenex Diagnostic Health Hub

A modern diagnostic lab and health management platform built for Biogenex Diagnostic.

## How to run locally

1. Install dependencies:
```sh
npm install
```

2. Run the development server:
```sh
npm run dev
```

3. Build for production:
```sh
npm run build
```

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase
